# ColorOSFrameLocker

[![Xposed](https://img.shields.io/badge/-Xposed-green?style=flat&logo=Android&logoColor=white)](#)
[![GitHub all releases](https://img.shields.io/github/downloads/Xposed-Modules-Repo/io.github.yukino1111.colorosframelocker/total?label=Downloads)](https://github.com/Xposed-Modules-Repo/io.github.yukino1111.colorosframelocker/releases)

适配 ColorOS 16 的高刷锁定模块，可接管系统策略。

模块仅作自用分享。

## 测试环境

> ColorOS 16

## 使用方法

1. 在 LSPosed 中启用模块
2. 勾选作用域
3. 重启设备
